Django New Features

github.com/django/new-features
Before we get to the next question, I need to provide some context. Last year, the Django Steering Council introduced a new mechanism to discuss and add features to Django. This moved feature discussion out of the issue tracker and into the new features repo. It allows everyone to easily chime in via emoji on ideas so we can see which features are beneficial. From there the Steering Council advances things based on consensus and volunteers. We'd love to know what features are useful and to get volunteers to help build things.

Django Probe (djangoprobe.org)


            uvx django-probe scan .      # View the payload
          

            {
              "dependencies":    {"asgiref": "3.12.1", ...},
              "django_settings": {"ALLOWED_HOSTS": 1, ...},
              "django_version":  "6.1.2",
              "files_scanned":   121,
              "patterns":        {"probe:auth_user_model_setting": 1, ...}
              "python_version":  "3.9",
              "usage":           {"django.contrib.admin.display": 7, ...},
            }
So Django Probe is tool that collects and shares how you use Django. It inspects the AST to collect which APIs, settings are being used, then generates a counts dictionary. It's intended to help maintainers understand if certain parts of Django are being used and to what extent. What's exciting about this is that it provides some evidence to back our general feeling. For example, the `extra()` queryset method has been borderline deprecated for years. We haven't deprecated it mainly because there wasn't a clear off ramp for people who are using it. The trouble is, we have no idea if anyone is actually using it. This tool could empower maintainers to take action sooner and make contributing more enjoyable.

Data Supported Decisions


            uv add django-experimental

            # In settings.py
            DJANGO_EXPERIMENTAL_FLAGS = {"ENABLE_NEWAUTH": True}

            # In pyproject.toml
            [tool.django_probe]
            packages = [ "django", "django_experimental" ]

            # Terminal
            uvx django-probe scan .
            > {"django-experimental": {"enabled_flags": ["ENABLE_NEWAUTH"] }}
Beyond the deprecation flow, this is also useful on the new feature side of things. We could collect information about how third-party projects are used. So we if had a django-experimental package with leading changes for people to trial out that gated features behind settings, we would be able to see how many projects are utilizing the experimental setting. This gives us more than a gut feel for how robust and well-used a particular feature is. This mentality of soliciting for feedback isn't anything new, but I'm hopeful the tooling and automation can make it easier for the community to share which parts of Django are useful.
